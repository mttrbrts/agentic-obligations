# Agent SaaS Authority Template

An Accord Project Cicero template that formalises a company's grant of scoped procurement authority to an AI agent. The contract defines the agent's identity, spend caps, permitted vendor categories, human-approval thresholds, obligations, and termination conditions.

## Purpose

This template is the contractual layer in the Phase 2 AP2 demo. When an AI agent (identified via the Google Agent Payments Protocol) proposes a SaaS renewal, an MCP server reads this contract's `data.json` instance and a `ProcurementRequest` payload, then computes an `AuthorizationDecision` (APPROVED / DENIED / REQUIRES_HUMAN_APPROVAL) along with the obligations triggered.

No Ergo/imperative logic lives inside the template — the schema alone describes inputs and outputs so the MCP server can produce a valid `AuthorizationDecision`.

## File layout

```
agent-saas-authority/
  package.json          # template metadata
  README.md
  model/
    model.cto           # Concerto model
  text/
    grammar.tem.md      # TemplateMark contract grammar
    sample.md           # rendered sample (generated by verify.mjs)
  data.json             # sample contract instance (Acme Corp / agent-007)
  request.json          # sample ProcurementRequest payload
  verify.mjs            # self-verification script
```

## Key contract fields

| Field | Sample value |
|---|---|
| Principal | Acme Corp (Delaware) |
| Agent ID | agent-007 (AP2 framework) |
| Max annual spend | USD 50,000 |
| Max per transaction | USD 5,000 |
| Human approval above | USD 2,500 |
| Permitted categories | saas-productivity, saas-devtools |
| Governing law | Delaware |
| Termination notice | 30 days |
| Audit retention | 1,825 days (5 years) |

## Running verification

```bash
npm install
node verify.mjs
```

This confirms the model loads, the grammar parses, `data.json` drafts cleanly to `text/sample.md`, and `request.json` validates against the Concerto schema.
